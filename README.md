# Skill Drops

Claude Code skills I use in my own work, packaged so you can install them. One drop at a time, shared first with the members of The Operator's Map.

Every drop is free. Nothing here asks for your email.

Each one is rated for how ready it is to use:

- **Works as-is**: install it and run it today.
- **Needs setup**: add your own key or connection first. The drop says how long that takes.
- **Pattern only**: the idea written out, for you to make your own.

## Installing a drop

1. Download the drop's zip from [Releases](../../releases), or click **Code → Download ZIP** on this page.
2. Unzip it and open the drop's `README-FIRST.md`. It has the two-minute demo and the full guide.
3. Copy the folders inside the drop's `skills/` into `~/.claude/skills/` on your machine.
4. Open Claude Code and type the skill's name, for example `/relationship-memory-setup`.

Run the demo before you point anything at your real data. Every person in a drop's demo data is invented.
